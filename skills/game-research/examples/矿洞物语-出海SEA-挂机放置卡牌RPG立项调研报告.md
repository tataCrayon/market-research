- **KPI 三级**：Demo 期（D1/D7 留存、CPI）→ soft-launch 90 天（回本信号、付费率）→ 12 个月（是否跑通 SEA 规模）

- **团队能驾驭（量化 kill 线）**：主程✅ / 数值·策划⬜缺口 / 美术✅但产能有限 / 买量⬜缺口(无经验) / 发行·本地化⬜缺口 / 合规✅(出海简单)。**缺口 3 个**；按 v1.2 硬线「缺口 ≥ 3 个 或 验证期 > 8 周即二判」——本想法站在 kill 线边缘，故 VERDICT 走「先验证」且严格 time-box。

> 三个测试：①一眼懂差别 ✅（可爱+挂机 vs AFK Journey 重度）②守 6–12 月再被抄 ⚠️（画风易抄，护城河在本地化+活动节奏）③做得出来 ✅（轻量卡通风降美术产能）。

## 5. 买量单位经济（ECON）

### 检索到的事实（基准，带来源日期）

| 指标 | 基准 | 出处 | 查证日期 |
|---|---|---|---|
| soft-launch mid-core 留存门 | **D1 35%+ / D7 15%+ / D30 8%+**；D1<30% 立即停 UA 修核心循环 | GameGrowthAdvisor 2026-04[^9] | 2026-09-21 |
| ARPDAU 健康线 | 广告型 >$0.15，IAP 型 >$0.30；mid-core 目标更高 | Zorka 2026 / Juego Studio[^10] | 2026-09-21 |
| eCPM（激励视频） | **$15–25**（约插屏 3 倍） | Zorka 2026[^10] | 2026-09-21 |
| SEA CPI | PH(TikTok) **$0.45**；全球 soft-launch 含 CA/AU/NZ $1–3 | 10100.com / GameGrowthAdvisor[^4][^9] | 2026-09-21 |
| 付费转化 | IAP 健康 >2%，头部 3–5%；RPG 首购平均安装后 1.7 天 | Zorka / SpielTimes[^10][^2] | 2026-09-21 |

- **CPI**：SEA 买量低位（$0.45 PH），但 quality 流量贵；soft-launch 若含 CA/AU/NZ 则 $1–3。**有效 CPI = 展示 CPI ÷ D1**（防「只看展示 CPI 自欺」）。
- **LTV**：IAP 为主（mid-core ARPU $1.5–2/MAU/月）+ 激励视频补 eCPM $15–25。混合 ARPDAU 目标 **>$0.30**（IAP-led 健康线）。假设项标 ⬜。
- **分成**：Google Play/iOS 30%；SEA DCB 运营商另分（接入即硬任务）。
- **生死公式**：`利润 = (LTV − CPI) × 规模`。SEA 低 ARPU（$8.7–24.6）靠**高 DAU 量 × 低 CPI** 撑，模型须给「自然量/CPI 腰斩」情景（DCB 接入失败 → 付费转化腰斩）。

### 盈亏平衡 SOM（双成本，v1.2）
含研发沉没 $30–60k + soft-launch $50–120k + 月度内容产能 + 合规 ≈ $80k–180k 刚性。SEA 低 ARPU 下，需 DAU 规模 × (LTV−CPI) 盖住；**eCPM/CPI 腰斩情景测试**：若 PH CPI 翻倍至 $0.9 或 DCB 接入失败致付费率腰斩，回本周期从 ~6 月拉长至 >18 月 → Verdict 降级。

## 6½. 验证阶梯（PROVE，v1.1 + 填 residual gap #5 移动端 soft-launch 门）

- **L0 概念测试（¥0）**：TikTok concept-ad（5 词卖点+可爱画风素材）测 CTR，证 M1 吸量。**无用户池的小团队可用自有社媒/小额投放做。**
- **L1 可玩切片（¥0，≤1 周）**：见 Step 6，证 M5 玩法成立。
- **L2 封闭 Demo（≤2 周）**：核心循环 + 留存埋点，测 D1/D7。
- **L3 soft-launch（PH + ID，8–12 周，$50–120k）**：读 **mid-core KPI 门**——
  - D1 **35%+** / D7 **15%+** / D30 **8%+**；ARPDAU **>$0.30**；eCPI（含 DCB 接入后）
  - **D1<30% 立即停 UA 修核心循环**（GameGrowthAdvisor 铁律）
  - 三留存未达 mid-core 基准 → 迭代或砍；ARPDAU<$0.30 且 IAP 转化<2% → 变现重做

**量化 kill 阈值（写入 VERDICT 放弃信号）**：D1<30% 停 UA；soft-launch 三留存未达 mid-core 基准→迭代或砍；ARPDAU<$0.30 且 IAP 转化<2%→变现重做。

**验证期 time-box（v1.2 硬纪律）**：L0/L1(¥0) ≤ 2 周、L2 ≤ 4 周、L3 ≤ 4 周，**总 ≤ 8–10 周到期必须二判**（✅立项 / 🔧改方向 / ❌放弃），不得「永远在填坑」。

## 7. 判决（VERDICT）

# 🧪 先验证

**一句话理由**：出海无版号（合规心脏解除）、RPG 品类 SEA 需求稳、轻量卡通风有本地化与产能优势、soft-launch 门清晰可测——但 M1 吸量未测、M5 玩法成立未实测、团队买量/发行 3 个缺口在 kill 线边缘、SEA 低 ARPU 下 LTV≥CPI 未验证。最值钱的动作是 **¥0 先证需求与玩法**，不是先烧 $50–120k soft-launch。

### 最值钱的一步（现在就做，单个动作）
> **不做任何研发，先发一条 TikTok concept-ad（可爱矿工挂机 5 秒循环 + 卡牌收集展示）+ 一个极简可玩切片给 5–10 个 PH/ID 目标用户 playtest。**
> 这条比写 3 个月代码值钱：它同时证 M1（吸量 CTR）与 M5（玩法成立），且成本 ≈ ¥0。

### 最便宜的验证（从 L0/L1 ¥0 起）
- L0（¥0）：TikTok concept-ad CTR 是否 ≥ 品类基准（可爱/休闲素材基准，需现场取）
- L1（¥0）：5–10 人 SEA 用户 playtest「想继续养吗」——证 M5
- 过线才进 L2/L3；**绝不跳过 ¥0 验证直接 soft-launch 烧钱**

### 放弃信号（观察到就停，含量化阈值）
| 观察到 | 含义 | 动作 |
|---|---|---|
| L0 CTR 低于可爱/休闲素材品类基准 | M1 吸量证伪 | 改钩子或砍 |
| L1 playtest「不想继续养」 | M5 玩法不成立 | 🔧 改方向 / ❌ 放弃（核心循环问题，买量拉不来） |
| soft-launch D1<30% 或 三留存未达 mid-core（D1 35%/D7 15%/D30 8%） | 产品问题 | 停 UA 修核心循环，修不好砍 |
| ARPDAU<$0.30 且 IAP 转化<2% | 单位经济崩 | 变现重做或放弃 |
| DCB 接入失败致 PH 付费率腰斩 | SEA 付费主通道断 | 🔧 改接运营商 / ❌ 放弃 SEA |
| 验证期 > 8–10 周仍未二判 | 无限验证 | 强制二判（立项/改/放弃） |
