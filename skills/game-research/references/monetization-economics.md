# 买量单位经济取证清单

> **这份文件只给「查什么」「去哪查」「怎么算」，不写死任何比例、CPI、eCPM 数字。**
> 买量成本、分成、ARPU 按季度变动，且高度依赖品类与渠道；写死即假证据。
> 用法：调研时取**当前年份**的基准，每条标 `来源 | 链接 | 查证日期 | 等级`，假设项标 ⬜。

---

## 一、利润公式（本 Skill 的算法核心）

```
利润 = (LTV − 买量成本) × 规模
```

- 当 **CPI > LTV**：买量越猛越亏，研发越精越死（指色网络「生死公式」）。
- 立项不必精算每档礼包，但必须回答 **LTV 与 CPI 的方向**（谁大）。

---

## 二、CPI（买量成本）—— 按渠道 × 品类取基准

| 来源 | 拿什么 | 入口 / 检索语句 |
|---|---|---|
| DataEye 买量数据报告 | 小游戏在投数、素材量、日耗、品类 CPI 趋势 | `dataeye.cn`；检索：`DataEye <当前年份> 小游戏 买量 报告 CPI` |
| 广大大 / App Growing | 竞品实际投放素材、预估 CPI/CPM | `bigbigads.com` / `appgrowing.cn`；检索：`<竞品> 投放 素材 CPI` |
| 七麦 / 点点数据 | 榜单、估算下载 | `qimai.cn` / `diandian.com` |
| 平台广告后台（腾讯广告/巨量） | CPM/CPI 官方基准区间 | `e.qq.com` / `oceanengine.com` |

**行业已观察（须带来源日期，勿当公式）**：
- 2025 小游戏买量日耗约 1.44 亿，在投游戏约 5.1 万款（+54%），素材 5000 万+（+97%）→ 内卷严重，CPI 上行。
- 休闲单用户买量成本高位约 ¥98（某趋势报告口径，需核验）。
- 健康基准参考：腾讯/巨量 CPM ¥35–80，Pangle 安装 ¥18–60，well-run CPI < ¥30，D7 留存 > 25%。

**打法**：直接看竞品在目标渠道**实际投放强度**（DataEye 在投数、素材量），排名与素材量就是它买量能力的体检报告。

---

## 三、LTV（用户终身价值）—— 分 IAA / IAP 算

- **IAA（广告）**：`LTV ≈ eCPM × 人均广告展示次数 ÷ 天数 × 留存加权`。eCPM 随品类/人群波动大，须取当前基准（⬜ 假设项要显式标注）。
- **IAP（内购）**：`LTV ≈ 付费率 × ARPPU × 留存加权`。
- 必须分 **D1 / D7 / D30** 留存档位给保守/中性/乐观三档，每档标假设来源。

**验证 LTV 的最低成本动作**：做可玩 Demo，小预算（¥2–3 万）买量，实测 D1/D7 留存与 eCPM，反推 LTV。

## 五、自然量比例（被低估的一项）

小游戏核心优势是**社交裂变降获客**（微信下拉/分享/搜索主动启动占比高）。立项须显式假设自然量比例（如 30%）并说明依据：
- 查竞品是否靠社交裂变（微信指数峰值、分享讨论量）
- 注意：2025 微信对诱导分享/强制广告审核加强，裂变门槛提升，自然量假设要保守

---

## 六、算盈亏平衡 SOM

```
盈亏平衡 SOM = (刚性月成本 + 买量投入) ÷ (LTV − CPI) × 规模系数
```

与市场 SOM 比对：
- 现实 SOM ≥ 盈亏平衡 SOM → 单位经济可行
- 现实 SOM < 盈亏平衡 SOM → Verdict 降级（涨价 / 换窄定位 / 换战场 / 放弃）
