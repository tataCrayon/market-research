# 版号与合规硬约束取证清单

> **这份文件只做两件事：给「查什么」的清单，给「去哪查」的入口。**
> 它**故意不写具体政策数字**——版号口径、申报周期、分成比例按季度变动，
> 任何写死在这里的数字，都会在下一次调研时变成假证据。
>
> **用法**：调研时按清单逐行走，每条结论回填到 SKILL.md 的「合规快照表」，格式：
> `结论 | 官方链接 | 查证日期 | 状态（✅通行 / ⚠️条件满足即可 / 🔴阻塞 / ⬜未取证）`
>
> **入口 URL 可能变更**。请以各平台开发者门户当前导航栏为准；链接失效时用「检索语句」重试，并把实际生效链接记进报告。

---

## 一查：版号口径（能不能开付费）——本 Skill 的头号取证陷阱

| 战场 | 必查项 | 入口 / 检索语句 |
|---|---|---|
| 微信小游戏 | 纯 IAA（广告变现）是否需要版号？含虚拟支付（IAP）是否需要？个人 vs 企业主体差异？电子版权认证能否替代软著？ | 微信开放社区 `developers.weixin.qq.com/community/minigame`；检索：`微信小游戏 纯广告变现 版号 要求 <当前年份>`、`微信小游戏 IAA 需要版号吗` |
| 抖音小游戏 | 同上，抖音口径 | 抖音小游戏开放平台 `microgame.bytedance.com`；检索：`抖音小游戏 版号 IAA IAP 要求 <当前年份>` |
| iOS / 安卓 App | 国产游戏必须 NPPA 版号；进口游戏额外文化审批 | 国家新闻出版署 `www.nppa.gov.cn`；检索：`游戏版号 申请 流程 <当前年份> 国产` |
| Steam / 出海 | 海外上架无国内版号；但若回国发行需补 | Steamworks；检索：`steam game publishing requirements` |

**⚠️ 关键陷阱（实战踩过）**：搜「小游戏 IAA 要不要版号」返回的前几条**几乎全是资质代办机构的营销页，且互相矛盾**（有的说纯广告不需要、有的说 2025 起不再豁免、有的说量大必须）。**处理规则**：
1. 多条冲突 → **只取①权威**（国家新闻出版署 / 微信开放社区官方文档）。
2. 只有③二手时 → 标 **⬜ 未取证**，并变成「查官方 / 打电话确认」的待办，不得写进判决依据。
3. 把实际生效的官方链接记进报告，附查证日期。

## 二查：内容红线（做了会不会被拒 / 版号被撤）

- 暴力/血腥/赌博/宗教/政治/性暗示/未成年婚恋等敏感内容（NPPA 2025 口径：血液变绿、骷髅变机器人、去英文日文等整改常见）
- 随机抽卡/礼包：概率必须公示并设置保底；**2025 起「抽卡/概率/保底」字样须改为「馈赠/惊喜」等**（务必现场核验当前表述要求）
- IP 改编：须提供完整授权链（公共 IP 如三国/西游也需改编授权）
- 高风险品类：棋牌、捕鱼类国内几乎拿不到版号，建议规避

检索：`游戏版号 内容 红线 <当前年份>`、`<品类> 版号 被拒 原因`

## 三查：未成年人合规（硬性前置）

| 项 | 涉及战场 | 入口 |
|---|---|---|
| 国家实名认证系统接入（公安部「网证」+ 中宣部「实名系统」） | 全国内战场 | 中宣部防沉迷实名系统（`https://jingsai.tele-code.com.cn` 等官方入口，以当前公告为准） |
| 国家未成年人防沉迷系统接入 | **2025 起小游戏也必须接入** | 同上；检索：`小游戏 防沉迷 接入 要求 <当前年份>` |
| 健康忠告提示 | 微信小游戏登录页固定位置展示 | 微信开放社区规范 |

**关键动作**：防沉迷与实名是版号/上线的硬前置，不是上线后补。立项阶段就要把它计入延误险。

## 四查：资质与备案（有没有资格做，全是日历天数）

| 项 | 涉及战场 | 入口 |
|---|---|---|
| 软件著作权（软著） | 国内发行普遍要求 | 中国版权保护中心 `ccopyright.com.cn` |
| 电子版权认证（上架加速，3-5 工作日 vs 软著 30 工作日） | 微信/抖音/各商店 | 各平台开放平台；检索：`电子版权认证 小游戏 上架` |
| 网络出版服务许可证 / 出版社挂靠 | 申请版号必须 | 有资质出版社（中手游/咪咕/盛趣等） |
| ICP 备案 / ICP 许可证 | 含内购需 ICP 证（注册资本≥100 万等） | 工信部备案系统 `beian.miit.gov.cn` |
| 网络文化经营许可证（文网文） | 含文字剧情等内容 | 属地文旅部门 |
| 企业主体 | 个人无法申请版号/开内购 | 市场监管局 |

检索：`<具体业务> 需要什么资质 游戏 上架 <当前年份>`、`<品类> 前置审批`

## 五查：申报周期与延误险（最容易被低估）

| 成本 / 周期项 | 天数 | 金额 |
|---|---|---|
| 软著办理或代办 | | |
| 电子版权认证（若走加速） | | |
| 出版社初审 | | |
| 省级局报送 → NPPA 审批（60–180 工作日常见） | | |
| 防沉迷/实名接入开发 | | |
| 首次提审到通过往返（留 2-3 轮） | | |

> **延误险 = 上表天数加总**，与研发周期**串行**。Verdict 里必须把天数写进「最值钱的一步」。
> 注意：2025 起 NPPA 每月仅审批 1 次、小游戏占比低，版号排队是真实日历风险。

---

## 查完必做

1. 回填合规快照表，**每条结论带链接 + 查证日期**
2. 标出所有 🔴 阻塞项——**未清零前，判决不得是「立项」**
3. 标出所有 ⬜ 未取证项——**默认计入风险**（版号口径冲突时尤其重要）
4. 把「延误险」天数加总，写进下一步计划
