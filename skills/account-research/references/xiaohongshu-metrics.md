# 小红书指标字典（account-research · 平台实例化 v0.1）

> **本文件是心脏 A（平台特异指标 × 可取证边界）的实例化**，只覆盖小红书；其他平台 v2+ 按同骨架另建字典，**禁止把本文件的指标口径套到其他平台**。
>
> **使用铁律**：
> 1. **口径先于数值**——记任何数字前，先标它的取证口径（公开页 / 仅作者后台 / 第三方工具 / 不可得）。口径不明的数字不进报告。
> 2. **数据等级跟取证方式走**——公开页手动记录 = ② 专业（可复核观察，须附链接 + 查证日期）；用户自有后台导出 = ②（第一方自证数据）；第三方工具 = ②/③-a（须标工具名 + 日期，工具口径 ≠ 平台口径）；无来源 = ⬜。
> 3. **定义本身也分级**——指标定义取自平台官方创作者文档 = ① 权威；取自民间框架 = ③-a 线索。**用 ③-a 定义算出的数字，最多支撑到「疑似」，进不了判决主证据。**
> 4. **禁写死基准区间**——「多少算正常 / 异常」一律现场取证（规则见 §5），本文件不提供任何基准数字。
> 5. **零爬虫**——只记用户可见的公开数据 + 用户手动粘贴 / 截图补充；本文件不包含任何采集技术方案。

---

## 1. 口径标注流程（Step 1 现场执行，逐条过）

```
这条指标 → 公开页（主页 / 笔记页）看得到吗？
  ├─ 看得到 → 口径 = 公开页（等级 ②，附链接 + 查证日期；以当天页面实际显示为准）
  ├─ 看不到 → 用户有该账号后台导出 / 愿意问号主吗？
  │    ├─ 有 → 口径 = 后台导出（等级 ② 第一方自证，注明导出日期）
  │    └─ 没有 → 第三方数据工具有这个指标吗？
  │         ├─ 有 → 口径 = 第三方工具（等级 ②/③-a，注明工具名 + 查询日期）
  │         └─ 没有 → 口径 = 不可得 → ⬜ 未取证 → 转手动补充任务（≤24h）→ 仍拿不到保持 ⬜
```

> **建库说明（2026-10-16）**：下表「口径（默认）」列为建库时的**结构性判断**（公开互动计数 vs 后台漏斗数据属结构性差异），但**当期公开页到底展示哪些数字，仍须按上面流程现场标注**——平台展示项会变，沿用旧口径视为未取证。

## 2. 账号层指标

| 指标 | 定义 | 拆解用途 | 口径（默认，须现场复核） | 取到后等级 | 常见误用 |
|---|---|---|---|---|---|
| 粉丝数 | 账号当前关注者量级 | 判断体量档位（对标可复制性的输入） | 公开页 | ② | 把粉丝数当影响力唯一指标——不看过往增速与互动质量 |
| 获赞与收藏（账号累计） | 主页展示的累计赞 / 藏 | 与粉丝数交叉看「内容资产厚度」 | 公开页 | ② | 单看累计数判断近期表现——须拉齐时间窗 |
| 笔记数 / 更新频率 | 主页笔记总量；近 30/90 天发布篇数 | 产能与 cadence 观察（死亡清单「产能不匹配」的判据） | 公开页 | ② | 拿日更对标的 cadence 要求周更能力的自己 |
| 简介 / 头像 / 背景图 | 账号自我声明 | 定位卡的线索（③-a，须与评论区证据交叉） | 公开页 | ② | 把简介直接当定位——那是账号的自我声明，不是证据 |
| 粉丝增长（日 / 周 / 月） | 新增关注曲线 | 判断账号所处阶段信号 | **仅作者后台**（对标拿不到） | ⬜ | 用粉丝数差值粗估增长——那是用存量猜流量，禁用 |
| 粉丝画像（性别 / 年龄 / 城市 / 兴趣） | 关注者构成 | 定位卡「为谁」的直接证据 | **仅作者后台 / 第三方工具估算** | ⬜ 或工具口径 | 把第三方工具的「估算画像」当事实引用（R5） |
| 账号权重 / 限流状态 | 平台无任何官方公开口径 | —— | **不可得** | ⬜ | **凭数据波动判「限流」= 相关当因果（R6），明令禁止** |

## 3. 内容层指标

| 指标 | 定义 | 拆解用途 | 口径（默认，须现场复核） | 取到后等级 | 常见误用 |
|---|---|---|---|---|---|
| 点赞 / 收藏 / 评论 / 分享 | 单篇公开计数 | 数据底稿主字段；赞藏比的原料 | 公开页 | ② | 只记赞不记藏——小红书素材型内容的核心信号在收藏 |
| 浏览 / 曝光量 | 单篇被看次数 | 一切比率指标的分母 | **多数情况仅作者后台**；当期公开页是否展示须现场标注 | ⬜ | 拿不到曝光时用「赞 ÷ 估算曝光」编互动率——分母造假 |
| 点击率（封面标题 → 正文） | 曝光 → 点击 | 结构拆解的封面 / 标题判据 | **仅作者后台** | ⬜ | 用「点赞高」反推点击率高——中间还隔着内容质量 |
| 完播率 | 视频看完比例 | 视频类对标的中段节奏判据 | **仅作者后台** | ⬜ | 拿抖音完播基准判小红书——跨平台移植（R3） |
| **赞藏比** | 点赞 ÷ 收藏 | 内容性质初判：图文工具型常收藏 > 点赞，情绪型常点赞 > 收藏 | 公开数据可算 | ② 算得，**解读方向是 ③-a 框架** | 把「收藏高」直接等同「有用」——还须评论区交叉验证 |
| 互动率 | (赞+藏+评+分) ÷ 分母 | 横向比「哪篇更能打」 | 分母口径必须与指标一起标注（曝光 / 粉丝数 / 篇均） | ② / ⬜ 视分母 | 不同分母的互动率放一张表比大小——口径不一致 |
| **爆文率** | 爆文篇数 ÷ 总篇数 | 账号稳定性的核心指标 | 公开数据可算，**但「爆文」定义必须先取证**（见 §4） | ② 算得，定义等级另标 | 引用一个没出处的「5% 算高」当标准（R4） |
| 单篇涨粉 | 该篇带来的新增关注 | 转化效率判据 | **仅作者后台** | ⬜ | 用篇均涨粉估算——同「粉丝增长」行，禁用 |
| 评论区需求词密度 | 求助 / 询问 / 「求链接」类评论占比 | 选题母题的需求验证（③-b 纪律：≥3 条独立评论且跨 ≥1 个月才计） | 公开评论区 | ② 观察，主张进结论前标注 | 把单条热评当全人群需求 |
| 发布时间分布 | 篇目发布时刻 / 星期 | cadence 与追热点节奏观察 | 公开页 | ② | 把「发布时间」当流量原因——相关 ≠ 因果（R6） |

## 4. 爆文率：定义分歧必须先取证（本字典最典型的「口径坑」）

「爆文」至少有三种常见定义，**同一样本下数字不同**：

| 定义 | 算法 | 来源等级 | 风险 |
|---|---|---|---|
| 绝对互动量阈值 | 单篇互动量 ≥ 某固定值 | ③-a（民间框架，阈值随时间 / 类目变） | 阈值过时 → 全表失真 |
| 相对账号自身 | 单篇互动 ≥ 账号中位数 × K 倍 | ③-a（K 值无共识） | K 每改一次，爆文率跳一档 |
| 平台推荐池口径 | 进入某流量层 | ①（**仅有平台官方创作者文档曾有相关说明时**，须现场查证当期口径） | 官方口径本身会调整 |

**纪律**：计算爆文率前，先在报告里写清「本报告采用定义 X（来源 + 链接 + 查证日期）」。三种定义都取不到 → 爆文率整列 ⬜，**不得选一个最顺眼的定义硬算**。定义分歧本身若影响结论，写入「数据不可证」统计并计入判决（⏸ 的触发条件之一）。

## 5. 基准区间取证规则（「多少算正常」）

**禁写死**：本文件及任何 account-research 报告，**不得出现未附链接的基准数字**（爆文率阈值、互动率区间、报价、粉丝增速……）。本字典不提供基准值，只提供取证规则。

**取证优先级（逐级降级，取到即停）**：

| 优先级 | 来源 | 等级 | 要求 |
|---|---|---|---|
| 1 | 小红书创作者服务中心 / 创作学院官方文档、官方规则公告 | ① | 附官方链接 + 查证日期；注明官方是否分品类 / 分形式给口径 |
| 2 | 专业数据工具公开报告 / 行业白皮书（新榜 / 灰豚 / 千瓜等公开发布物） | ② | 附链接 + 发布日期；**注明是工具口径**（样本与算法与平台不同） |
| 3 | 民间拆解框架 / 运营课程 / SEO 博客 | ③-a | **只能当线索**：转成「待核验主张」，单独引用不得支撑判决 |

**三条硬要求**：
1. **基准必须带适用条件**：类目、账号量级、内容形式（图文 / 视频）、时间窗。一个「全站平均」基准套到小众类目是错的——引用时条件不匹配 = 未取证。
2. **取不到 → 写 ⬜，判决不得依赖**：报告可以写「该基准未取证，因此不对『这篇算爆文』下结论」，**不得为了结论完整而挑一个能用的数字**。
3. **二手来源只转待办**：③-a 给出的区间，处理动作是「按该区间去平台官方渠道核实」，不是「采用该区间」。

## 6. 小红书特有概念速查（拆解时会碰到，各带纪律）

| 概念 | 是什么 | 拆解时的纪律 |
|---|---|---|
| 专业号 | 平台的认证 / 经营身份（有后台数据能力） | 对标是否专业号影响可见数据与变现路径判定；身份变化以当期页面展示为准 |
| 蒲公英 | 平台官方内容合作（报备商单）入口 | 商单痕迹是变现拆解的 ①/② 级可见证据；但**成交价格不可见 → ⬜** |
| 薯条 / 内容加热 | 付费加热工具 | 笔记「看起来爆」可能是加热结果——公开页通常无标识，**不得凭数据波动推断投放**（R6），只能作为 ⬜ 记录「是否存在投放不可证」 |
| 合集 / 专栏 | 内容组织结构 | 结构拆解的素材：看账号如何把内容装进产品化容器 |
| 置顶笔记 | 账号自选的门面 | 定位卡的重要线索（账号最想被看到什么），但仍是自我声明（③-a） |
| 评论区「求链接 / 怎么买」 | 需求与成交信号 | ③-b 纪律：≥3 条独立评论且跨 ≥1 个月才计为需求信号 |

> 概念细节（功能边界、规则）会随平台调整变化——**以上均为拆解时的观察框架，规则细节一律以当期官方页面为准**，发现冲突时以现场查证结果修订本表并在构建实证记录。

## 7. 查证入口（只给入口，不写死 URL）

平台页面结构会变，**入口变了就重新找，禁止用记忆里的旧链接**：

| 入口 | 查什么 | 说明 |
|---|---|---|
| 小红书创作者服务中心 / 创作中心（官方） | 指标定义、规则口径、创作者文档 | ① 权威第一来源；指标口径与规则以其为准 |
| 专业号后台（经账号所有者授权导出的场景） | 曝光 / 点击 / 完播 / 粉丝画像 | ② 第一方自证数据；对标场景下默认不可得 → ⬜ |
| 平台规则中心 / 社区规范 | 违规口径、限流与处置规则 | ① 权威；涉及「账号是否违规」的唯一可引来源 |
| 第三方数据工具公开报告（新榜 / 灰豚 / 千瓜等） | 基准区间、行业横评 | ②/③-a；**注明工具口径 + 日期**，不得与平台口径混用 |
| 目标账号公开页（主页 / 笔记 / 评论区） | 一切对标数据的第一现场 | ②；每条记录附链接 + 查证日期 |

## 8. 记录模板（Step 1 数据底稿用）

```markdown
### 指标记录
- 指标：<名称>  数值：<值>
- 取证口径：<公开页 / 后台导出 / 第三方工具(工具名) / 不可得>
- 数据等级：<① / ② / ③-a / ⬜>（若为 ③-a 定义算出，注明「定义：<来源+日期>」）
- 来源链接：<URL 或「用户粘贴/截图，取证方式+日期」>
- 查证日期：<YYYY-MM-DD>
- 备注：<适用条件：类目 / 量级 / 内容形式 / 时间窗；口径存疑处>

### ⬜ 未取证登记
- 数据项：<名称>  影响层：<定位 / 选题 / 结构 / 变现 / 账号层>
- 已尝试：<取证路径列表>
- 处理：<手动补充任务(负责人+截止≤24h) / 保持 ⬜>
- 对判决的影响：<是否阻塞关键层——阻塞则计入 ⏸ 触发条件>
```

## 9. 平台特异性备忘（为什么小红书单独建字典）

- **数据封闭性强于公众号 / CSDN**：公开页核心可见的是互动计数，漏斗数据（曝光 / 点击 / 完播 / 画像）默认不可得。**这不是缺陷而是试金石**——⬜ 纪律在这里被真实数据撞出来，比在一个数据全公开的平台上更能验证本 Skill 的成色。
- **图文与视频指标侧重不同**：图文重收藏与评论结构，视频重完播与节奏；跨形式对比指标前先分形式。
- **跨平台移植是最高频谬误**：抖音看完了、公众号看打开率、B 站看三连、小红书看赞藏比——**每个平台的心脏指标不同，混用即 R3 违规**。
