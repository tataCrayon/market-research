# 用工性质识别指南（Employment Nature）

> **用途**：`career-research` Step 1 MAP / Step 2 PROFILE / Step 4 FILTER 的必查维度。
> **为什么必须查**：**同一个岗位名，用工性质不同 = 完全不同的选项。** 不标用工性质，会把「外包岗」当成「自有岗」计入岗位供给，虚增机会；也会让求职者在「能进」之后才发现履历含金量、福利、稳定性的差异。
> **铁律**：**只标性质与事实影响，不预设好坏、不做评价性排序。** 外包对有些人是最快的入口、对另一些人是履历风险——报告陈述客观差异，判断留给用户。
> **禁止写死**：具体公司名单会变，**一律现场核验**（见第四节三个入口）。

---

## 一、四分法：用工性质到底有哪几种

| 类型 | 劳动合同甲方 | 日常管理方 | 典型招聘方 | 对求职者的含义 |
|---|---|---|---|---|
| **自有（正式）** | 实际服务的用人企业本身 | 用人企业 | 用人企业 | 标准情形：福利、晋升、履历都属于该企业 |
| **劳务派遣** | **派遣公司**（须持《劳务派遣经营许可证》） | **用工单位直接管理**（人事权在派遣公司） | 派遣公司 / 用工单位名义 | **法定只能在三性岗位、比例 ≤10%**；超范围即违法派遣 |
| **岗位外包（BPO）** | 外包公司 | 外包公司 | 外包公司 | 业务整体外包，稳定性一般，业务脱离甲方核心 |
| **项目外包 / 驻场人力外包**（Staff Augmentation） | 外包公司 | **以甲方现场管理为主** | 外包公司 / 常挂甲方名头 | 履历含金量风险最高：易被后续雇主判为「外包履历、无核心项目」 |

> **常被混淆的一类**：「大厂子公司 / 关联公司直签」**不是外包**，但它也**不是母公司直签**。这是一个独立的第五种情形——报告里要单列，别混进「自有」，也别混进「外包」。

## 二、法定杠杆：用法律口径反向识别（①权威）

《劳动合同法》《劳务派遣暂行规定》（人社部令第 22 号）给了两个**可用来反向识别**的硬口径：

| 口径 | 内容 | 怎么用来识别 |
|---|---|---|
| **三性岗位** | 劳务派遣**只能**用于 **临时性**（存续 ≤6 个月）、**辅助性**（非主营业务）、**替代性**（原岗人员脱产/休假期间替代） | 一个**长期（>6 个月）+ 涉及主营业务 + 非替代性**的岗位，若被说成「派遣」，则属**「假外包、真派遣」的违法用工**——求职者可据此判定风险并追问 |
| **比例 ≤10%** | 用工单位使用的被派遣劳动者**不得超过其用工总量的 10%** | 某企业宣称「大量派遣岗」时与 10% 上限矛盾 → 提示其真实用工结构需核验 |
| **禁止派遣岗位** | 政府专职消防员、新闻单位采编播管、法检书记员、公安警务辅助人员等须**直接建立劳动关系** | 这些领域出现「派遣」即违法 |
| **辅助性岗位程序** | 用工单位使用辅助性岗位须经**职代会/全体职工讨论 + 公示** | 可作为追问点 |

> **「假外包、真派遣」是违法行为**，且已被列入 2025 年人社部等五部门清理整顿人力资源市场秩序专项行动的重点，明确包括以「人力资源服务、共享、代理、合作以及转包、加盟」等方式的变相派遣。
> **判定原则是「事实优先」**：看**人身从属性、经济从属性、组织从属性**（谁考勤、谁考核、谁发薪、谁定规章）。
> 来源：①权威（《劳动合同法》《劳务派遣暂行规定》及地方人社局指引/提示函，如西安市未央区人社局、乌海市人社局）；②专业（《工人日报》2025-08-21 报道，中国社科院法学所与高校劳动法学者访谈）。

## 三、识别信号：三级 + 反例

### 🔴 强信号（命中 **1 条**即「高度疑似」，必须进入核验流程）

- 招聘方名称含 **人力资源 / 人才服务 / 劳务 / 派遣 / 外包**，或简介**无自研产品**、只写「为 XX 行业提供技术服务 / 服务于 XX 客户」
- JD 出现 **驻场 / 甲方现场 / 外派 / 派遣 / 用工形式：外包（派遣）** 等词
- 面试地点在**第三方公司或酒店**，面试官是第三方 HR（而非用人方业务负责人）
- **同一份 JD 在多家不同公司名下重复发布**
- 经核验，招聘方**经营范围含「劳务派遣」「人力资源服务」**（工商公示可查）

### 🟡 中信号（**≥2 条叠加**才判「疑似」，单条不判）

- 常年大量招人、岗位高频刷新、单岗位招聘人数呈**批量**（10 人、25 人量级）
- 薪资结构与行业不符：**低底薪 + 高项目奖金**、按天/按人头计
- 岗位职责写「**协助甲方完成**」「按甲方要求执行」「项目交付」，而非「负责 XX 模块 / 需求分析 / 架构设计」
- 任职要求强调「**能出差 / 接受驻场 / 抗压**」，专业技能描述宽泛通用
- 岗位名后缀带（外派）（外包）（项目制）
- 社保公积金**按最低基数**（常需入职或从在职者处得知）

### ⚪ 弱信号（**只能当线索，禁止单独判定**）

- 公司名含「科技 / 信息 / 技术服务」
- 办公地址多地分散
- 无专利/软著（需查证，且不构成判定依据）

### 🚫 反例（这几条用来**防误判**，同样重要）

| 易误判 | 正确判断 |
|---|---|
| 名称含「科技/信息服务」就判外包 | **错**。大型 IT 实施/集成商本身就是甲方雇主，其自有员工不是外包 |
| 「猎头 / 代招」标记就判外包 | **错**。猎头只是**招聘渠道**，劳动合同仍可能与用人企业直签 → 必须问清**合同甲方** |
| 大厂「子公司 / 关联公司」直签就判外包 | **错**。是**第五种情形**（非母公司直签），单列 |
| 批量招聘就判外包 | **错**。业务扩张期同样会批量招人 → 中信号需叠加 |
| JD 出现「项目制」就判外包 | **弱**。「项目制」也是很多甲方自研团队的常规表述 → 需叠加其他信号 |

> **判定必须落到两个法律事实**：**劳动合同甲方** 与 **社保公积金缴纳主体**。话术、公司名、JD 用词都只是线索。

## 四、三个核验入口（把「疑似」变成「确定」的唯一方法）

> 📋 **常见服务商名单见 [outsourcing-suppliers.md](outsourcing-suppliers.md)**——它只是**核验触发器**（看到招聘方在名单上就提高核验优先级），**不是判定依据**。唯一判据仍是下面这三个入口。

| # | 入口 | 查什么 | 等级 |
|---|---|---|---|
| 1 | **国家企业信用信息公示系统 / 爱企查 / 企查查** | 招聘方**经营范围**是否含「劳务派遣」「人力资源服务」；是否为大型集团关联方 | **①权威**（工商登记信息） |
| 2 | **面试必问三句** | ①「劳动合同的甲方是哪家公司？」②「社保公积金由哪家公司缴纳？」③「是否有长期驻场要求？」 | ②（对方口头答复，**须落到合同才算数**） |
| 3 | **offer / 劳动合同盖章主体 + 社保缴纳主体** | 两者是否一致，是否等于你实际服务的业务方 | **①权威**（法律事实） |

**面试必问三句的追问法**：
- 若对方答「合同我们签，上班在甲方」→ 已明确是**外包/派遣**，继续问「属派遣还是岗位外包？甲方是哪家？」
- 若对方答「我们给 XX 大厂做项目」→ 问「是长期驻场还是项目期驻场？项目结束时如何安排？」
- 若对方回避或含糊 → **按疑似处理**，标 ⚠️ 并写进差距清单

## 五、对调研输出与判决的影响

### 1. 岗位清单表：`用工性质` 成为必填列

```
| post_id | 岗位名 | ... | 用工性质 | 判定依据 | 置信度 |
```
取值：`自有` / `劳务派遣` / `岗位外包` / `项目外包·驻场` / `子公司关联直签` / `⚠️ 疑似未取证`

**置信度**：高（经入口 1 或 3 核验）/ 中（强信号 1 条）/ 低（仅中信号叠加）

### 2. 命中矩阵：新增「用工性质」维度行

对很多求职者，用工性质是一个**独立的开关**，不是加分项：

```
| 用工性质 | 岗位实际值（取证） | 画像期望 | 命中 | 证据 |
|          | 项目外包·驻场     | 自有     | ❌   | 招聘方为人力资源公司；面试地点第三方 |
```

### 3. 对判决的影响点

| 影响面 | 说明 |
|---|---|
| **不改变硬门槛判定** | 门槛就是门槛，外包岗也可能卡学历/年限 |
| **影响轴 E 上线后现实** | 福利差异、转正可能性、项目结束后的安排，都属「入职后能否站稳」 |
| **影响轴 F 机会成本** | 「进外包档」与「深耕原岗」的期望回报必须一起比 |
| **影响放弃信号** | 若**可投入口大量是外包**，判决必须显式写清：能进的是外包档，履历含金量风险是放弃信号的一部分 |

### 4. 若核实为**违法派遣**（违反三性 / 超 10% / 禁用岗位）
标 🔴 并写进风险项——这不是「选择问题」，是**合规风险**（协议可能无效、事实劳动关系认定、连带责任）。

### 5. 反歧视纪律（与 R1 一致）
识别用工性质是**为个人决策服务**，**不得**：
- 据此对**人**做判断或排序（外包从业者不是「次级人才」）
- 使用贬损性表述；只陈述**性质与客观影响**（合同主体、福利口径、履历可核验性）
- 把它变成「岗位优劣排行榜」——不同人对同一性质的效用不同

## 六、自查清单

- [ ] 岗位清单表每一行都有 `用工性质` + 判定依据 + 置信度，无空白
- [ ] 强信号命中项都进入了核验流程，未停留在「疑似」
- [ ] 中信号是 **≥2 条叠加**才判定的，没有单条下结论
- [ ] 没有凭**公司名**一刀切判定（反例表逐条核对过）
- [ ] 「猎头/代招」与「外包」已区分（合同甲方才是判据）
- [ ] 「子公司/关联公司直签」已单列，没混进「自有」或「外包」
- [ ] 命中矩阵含「用工性质」维度行
- [ ] 若可投入口多为外包，判决的放弃信号已含履历含金量风险
- [ ] 表述中立，无贬损性、无对人群的排序或评价
- [ ] 涉及违法派遣（三性/比例/禁用岗位）的已标 🔴 合规风险
