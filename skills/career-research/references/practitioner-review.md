# 从业者审视：职业领域八轴实例化（落地镜）

> **通用八轴原文见 [`docs/dual-mirror-review.md`](../../docs/dual-mirror-review.md)，本文不重复。**
> 本文只写：八轴在**职业 / 岗位调研**里的具体问法、真实 kill 案例、以及本领域的补充轴。
>
> **视角**：一个真的招过人、带过团队、见过转岗失败与岗位蒸发的**用人方 / 业务负责人 / 资深从业者**。

## 一、八轴在职业领域的实例化

| 轴 | 通用质问 | **职业领域的从业者问法** | 判据 |
|---|---|---|---|
| **A. 成本完整性** | 一次性成本算了吗 | 「转型成本算全了吗——学习期、证书费、**空窗期收入损失**、**职级回退导致的降薪**、搬迁/通勤？还是只算了『薪酬上限』？」 | 报告是否给**转型总成本（含降薪与空窗）**；只给目标薪酬不给转型成本 → ⚠️ |
| **B. 生产现实** | 长线产能扛得住吗 | 「这个岗位入职后 6–12 个月的**真实产出要求**是什么？新人熬得过学徒期吗？还是报告只写到『拿到 offer』？」 | 是否评估**入职后存活**（试用期考核、前 6 个月交付压力）；只写到拿到 offer → ⚠️ |
| **C. 团队可持续性** | 缺口到几个 kill | 转岗版：「技能缺口到几个会 kill？**家庭/年龄/房贷**这类不可忽略的约束评估了吗？」<br>招聘版：「这个岗一个人扛得住吗，还是要配 N 个人？」 | 缺口是否量化到 **kill 线**（如「≥3 项需补且 time-box 内补不完即换路径」）；只列不判 → 🔴 |
| **D. 平台政治** | 平台可控变量风险加权了吗 | 「这个岗位的需求是**雇主真需求**还是**政策/资本/媒体推动的泡沫**？风口退了岗位还在吗？」 | 是否把**政策补贴 / 资本周期 / 媒体热度**当风险加权而非定值假设 → ⚠️ |
| **E. 上线后现实** | 首月好 ≠ 长期好 | 「**入职 ≠ 站稳**。35 岁之后这条路径还通吗？岗位被折叠/被 AI 替代的时间窗估过吗？」 | 是否给**职业周期的衰减与替代风险**（岗位半衰期、年龄结构）；只给入职时点 → ⚠️ |
| **F. 机会成本** | 比过其他选项吗 | 「同样的 8–12 个月，用来**深耕原岗位**（升职加薪 / 积累管理）期望回报谁高？还是只有『转』这一个选项被评估了？」 | GATE 是否比过**「转」vs「不转/深耕」**；只评估转岗 → ⚠️ |
| **G. 验证动作真实可行性** | 小团队真做得到吗 | 「说『先做个作品』——一个在职、有家庭、每天只有 2 小时的人，8 周真做得出来吗？」 | L0/L1 验证是否评估**个人可用时间与执行条件**；默认有无限时间 → ⚠️ |
| **H. 退出纪律** | 验证期 time-box 了吗 | 「『先补短板』没有截止日，就会变成**永远在准备、永远不投**。投出去的份数、面试转化率有硬线吗？」 | 是否给**验证期上限 + 到期二判 + 可证伪的投递/面试阈值**；只给阈值不 time-box → ⚠️ |

## 二、职业领域的两个补充轴（通用八轴没覆盖）

| 轴 | 从业者问法 | 判据 |
|---|---|---|
| **I. 岗位名真实性** | 「你调研的这个名字，雇主真的在招吗？还是只有媒体和培训机构在用？」 | 是否用**真实 JD + 官方职业编码**交叉验证岗位名；只有媒体/机构来源 → 🔴 |
| **J. 硬门槛的隐性解释** | 「『3 年相关经验』——**相关**是谁定义的？『本科及以上』在筛简历系统是硬过滤还是人工可议？」 | 是否逐条取证硬门槛的**实际执行口径**（筛简历系统 vs 人工）；凭「应该可以放宽」→ 🔴 |

> **I/J 两轴是职业领域专属**，也是最容易让一份「方法完美」的报告在真实招聘里直接失效的地方。
> 实测（2026-09-21）：独立岗位名「提示词工程师」在收缩，技能被折叠进 AI 应用开发 / AI 产品经理 / 解决方案架构师——**按岗位名调研会得到完全错误的行动清单**。

## 三、职业领域真实 kill 案例（写报告时要想到这些）

| 现实 | 从业者视角的解释 |
|---|---|
| **岗位名蒸发** | 招聘页不再用这个名字，但技能需求还在——只是搬到了别的岗位名下。按旧名字准备 = 全错。 |
| **「相关经验」卡死转岗者** | 总工龄 10 年、相关经验 0 年，在筛简历阶段即淘汰。这是转岗失败第一位原因，且 JD 里只有两个字。 |
| **风口岗的周期性** | 政策补贴与资本推动的岗位，随补贴退坡快速收缩。健康度判定必须区分「雇主真需求」与「政策/资本驱动」。 |
| **转型成本被系统性低估** | 人们只算「目标岗薪酬 − 现薪酬」，不算空窗、降薪、职级回退、学徒期低绩效奖金。真实回本周期常是估值的 2–3 倍。 |
| **「先准备再投」变无限延期** | 没有 time-box 的「先补短板」是最温和也最致命的失败模式——一年后仍在准备，且市场已变。 |
| **培训机构数据是反向指标** | 机构招生页里的「人才缺口 X 万」「月薪 X 万」与岗位真实需求**负相关**：越需要招生，越说明这个名头被热炒。 |

## 四、使用方法

```
STATE   — 一句话说清职业判决 + 它依赖的真实世界前提
ATTACK  — 沿八轴 + I/J 两轴发问；每条必须附「从业者会怎么处理」
VERDICT — 逐项判：守住 / 补强 / 推翻
COMMIT  — 写下报告要补的章节（回写 SKILL.md 的，进构建实证）
```

**铁律：批评必附货。** 只拆不建等于噪音。每条 ⚠️/🔴 必须同时给替代处理（如「空窗期成本进转型成本」「验证期 ≤8 周 + 投 20 份 0 面试即停」），否则禁止出口。

**不死磕完美**：转岗本就带着缺口。目标是「把盲区摊开、把最脆前提标红」，不是逼出零风险报告。
