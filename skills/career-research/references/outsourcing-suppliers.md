# 外包 / 人力资源服务供应商名单与核验（Outsourcing Suppliers）

> **用途**：`career-research` Step 1 MAP / Step 2 PROFILE 的**核验触发器**——看到招聘方出现在这份名单里，就**提高用工性质的核验优先级**。
>
> ## ⚠️ 使用声明（先读这段，否则会误用）
>
> | 这份名单**是** | 这份名单**不是** |
> |---|---|
> | **核验触发器**：提示你去查合同主体 | **判定依据**：不能据此判「这个岗位一定是外包」 |
>
> **三条必须记住的限制**：
> 1. **在名单上 ≠ 这个岗位是外包**。这些公司**自己也招员工**（做交付、销售、内部职能、自有产品），其自有岗位就是自有岗。
> 2. **不在名单上 ≠ 是自有岗**。名单不可能穷尽，尤其区域/中小服务商数量巨大且变动快。
> 3. **唯一判据仍是红线 R6 的两个法律事实**：**劳动合同甲方** 与 **社保公积金缴纳主体**。名单只影响**核验优先级**，不影响结论。
>
> **时效**：名单取证于 **2026-09-21**。公司会转型、更名、被收购（例：文思海辉现属中电金信）。**使用前必须按第七节复核**，并优先使用第六节的 ①权威 入口。

## 一、为什么给名单、又为什么不能只有名单

**给名单的理由**：岗位核验的成本主要在「知道该去查谁」。看到招聘方是个人力资源公司却不知道它的业务属性，最容易漏检——`AI应用方向-职业调研报告.md` 里把「科锐国际」当雇主写进岗位表，就是这么漏的。

**不能只有名单的理由**：本领域的核心纪律是「**判据只有合同甲方与社保主体**」。如果名单被当成判决书，就变成了自己 R6 明令禁止的「凭公司名一刀切」——既会误伤（大型 IT 服务商本身也是甲方雇主），也会漏判（不知名的小服务商）。

**结论**：名单 + **可自我复核的入口** + **明确的维护纪律**，三者缺一不可。

## 四、C 类：区域 / 中小人力外包服务商

**不列名单**——数量巨大、变动最快、且多数无公开可核验来源。改为给**识别特征**：

- 公司名含「**人力资源 / 人才服务 / 劳务 / 派遣 / 外包**」
- 简介无自研产品，只写「为 XX 行业提供技术服务 / 服务于 XX 客户」
- 单城市或少数城市密集布点，招聘岗位批量且常年刷新
- 工商**经营范围含「劳务派遣」「人力资源服务」**

→ 这类公司一律走**第六节 ①权威 入口**核验，不靠名单。

## 四·五、本地名单自建区（维护流程产出的样本：杭州 / 浙北）

> 通用名单（第一~三节）解决「看到这家要提高警觉」，**本地名单**解决「这个城市到底有多少家」。
> 本节是 **7.3 全量复核流程第③步「批量发现本地服务商」** 的**产出样例**，全部来自 **①权威**（人社局年度核验公示）与工商信息，**每条可追溯到公示原文**。
> 用户所在地**应照此自建**，不要依赖本节的杭州样本。

### ⚠️ 先记住这个反直觉事实（临平区 2025 年度核验公示）

> 临平区截至 2025-12-31 已审批（备案）且存续的劳务派遣单位 **233 家**；参加核验 163 家，**通过核验 147 家**；
> 而在这 **147 家通过核验**的单位中——**实际开展劳务派遣业务的只有 61 家，未开展的有 86 家（占 59%）**。

**结论：持有《劳务派遣经营许可证》≠ 这家公司在实际做派遣或外包。** 它只代表「有资格」。
照原始名单把 233 家全当外包公司，会**一次性误伤过半**。

> **顺带发现的错误用法**：不少单位**名里有「人力资源」「服务外包」，实际主营业务是安保、物业、建筑劳务、供应链**（见临平名单内的多家「保安服务」「物业管理」公司）。所以**公司名比许可更强的误导线索**。

## 五、名单的三级使用流程

```
1️⃣ 匹配  —— 招聘方出现在本名单？
            否 → 不降低核验标准，仍走第 2 步（名单不穷尽）
            是 → 提高核验优先级，进入第 2 步

2️⃣ 核验  —— 走第六节入口（①工商经营范围 / ②面试必问三句 / ③合同与社保主体）

3️⃣ 判定  —— 得到「用工性质 + 判定依据 + 置信度」，写入岗位清单表
            ★ 名单本身不产生结论，只产生「该查」的提示
```

**面试必问三句**（把「疑似」变「确定」）：
1. 「劳动合同的甲方是哪家公司？」
2. 「社保公积金由哪家公司缴纳？」
3. 「是否有长期驻场要求？」

```text
<城市>/<区> 人力社保局 行政许可决定清单 劳务派遣    # 动态：新办/变更/延续/注销
<城市> 取得人力资源服务许可 经营性机构 名单
<公司全称> 经营范围 劳务派遣 人力资源服务          # 关键：区分「有资格」与「在做」
<公司全称> 年报 灵活用工 收入 占比
<公司全称> 信用中国 行政处罚
```

> **为什么人社局名单最可靠**：它是**政府行政许可+年度核验**的产物，逐地覆盖（可细到区县），且**不会营销包装**。缺点是只覆盖「派遣」许可，不覆盖「岗位外包/项目外包」；后者要靠工商经营范围 + 合同主体判。

### 7.3 全量复核流程（季度）

```
① 逐条核验存续  —— 公司是否仍在营、是否更名、业务是否转型

③ 批量发现新条目 —— 用人社局公示名单获取本地服务商（见下）

⑥ 更新 7.1 状态总览的「下次复核日期」
```

**批量发现本地服务商的方法（产出比网络榜单可靠得多）**：
```text
<城市> 劳务派遣单位 名单 公示 核验         # 人社局年度核验公示
<城市> 人力资源服务机构 名单 公示

```

### 7.4 单条追加流程（标准条目 schema）

新增条目**必须填满以下字段**，缺任一字段即**不得收录**：

| 字段 | 规范 | 例 |
|---|---|---|
| `公司全名` | 工商全称 | 中软国际科技服务有限公司 |
| `常见简称/别名` | 用于检索，含曾用名 | 中软国际、Chinasoft |
| `类别` | A1 央企国资 / A2 上市 / A3 合资外资 / A4 民营区域 / A5 平台型 / B1 国内头部 IT / B2 其他 / B3 全球系 / B4 特殊形态 | A2 |
| `公开业务特征` | 官网/年报里的原话级描述 | 灵活用工收入占比超 95%（年报） |
| `是否同时是甲方雇主` | **必填**，防一刀切 | 是（有自有解决方案与交付团队） |
| `主体类型` | **必填**：`独立法人` / `分公司` / `集团母公司下的某子公司`（写法：`<子公司全名>（<母公司简称>全资/控股子公司）`） | 分公司（浙江锦阳…富阳分公司） |
| `许可事实` | **必填**：许可证编号 / 在哪一级人社局的哪份公示里出现过 / 核验年度 | 钱塘区人社 2025 年度核验合格名单第 37 条 |
| `是否实际开展派遣业务` | **能查到就填**，`开展` / `未开展` / ⬜`未取证`（⚠️**许可 ≠ 实际开展**，见 §四·五） | ⬜未取证 |
| `来源` | 可核验链接或文件（年报/官网/人社公示/工商登记） | 上市公司年报 / 钱塘区人社公示 |
| `证据等级` | ①/②/③-a（**③-b 一律不得收录**） | ② |
| `取证日期` | YYYY-MM-DD | 2026-09-22 |
| `下次复核` | 取证日期 + 3 个月 | 2026-12-22 |
| `状态` | 在效 / 待复核 / 已失效 / 已更名 | 在效 |

> **「公开业务特征」一栏在 ①权威 来源下天然取不到**——人社公示只给「有没有许可」，不给「做什么业务」。
> 这种情况**必须写 `⬜未取证`，不得凭公司名脑补业务描述**（例如把名字带「保安」「物业」「供应链」的公司描述成外包是其全部业务）。
> **⛔ 必填项与①权威来源冲突时的解决顺序**：`许可事实`（必填、可证）优先；`公开业务特征` 与 `是否同时是甲方雇主` 允许 **⬜未取证** + **状态记为「待复核」**，但**必须写明二次取证的入口**。
> ⚠️ **「⬜未取证」不是「允许不查」**——一条跨两个复核周期仍是「待复核」的条目，应降为 **已失效** 或直接移除，不能长期以 ⬜ 的姿态留在名单里充当装饰。

### 7.5 变更流程（更名 / 被收购 / 转型）

1. **保留旧名做检索别名**（旧名仍会出现在历史上的 JD 里，删掉旧名＝未来检索失效）
2. 状态改为 `已更名 → <新名>` 或 `已失效`
3. **不删除原条目**——历史记录本身就是「名单会过期」的证据
4. 记入变更日志，**标注 30 天内完成**

### 7.6 八条硬纪律

1. **禁止收录无来源的公司名**——每条必须有可核验来源
2. **禁止收录**平台吐槽、匿名爆料、无来源的「避雷名单」——那是 ③-b
3. **必须填「是否同时是甲方雇主」**——不填就不允许收录（这是防一刀切的最后一道闸）；①权威来源取不到时写 ⬜ 并转「待复核」，**不得脑补**
4. **禁止删条目**——只改状态（名单的可信度依赖可追溯的历史）
5. 用户所在地的服务商**优先按 7.3 的官方入口自建**，不依赖本文件的通用名单
6. **许可 ≠ 实际开展业务**——临平区样本：通过年检的 147 家里仅 61 家（41%）实际开展派遣业务。**不得把持牌名录整体等同于外包公司名单**
7. **判定精确到法人全称，不精确到品牌名**——同一集团内母公司可以明文排除劳务派遣、子公司可以同时持有派遣许可并承接人力资源外包（信雅达样本，见 §四·五 D2）。看到集团名时**必须问「合同盖的是哪个法人的章」**
8. **「服务人次 / 在册外包员工数」不得当作「自有员工数」**——人力资源类公司公开宣传的大数通常是**服务规模**（例：锦阳集团「年服务 30 万人次」vs「在职管理人员 2700 余人」），混用会得出完全相反的性质判断

## 八、中立表述纪律（与红线 R6 一致）

- 本文件描述的是各公司**公开宣传的业务范围**，**不构成对其优劣的评价或推荐**。
- 用工性质是**事实标注**，不是价值判断。**不得**据此贬损任何公司或从业者，**不得**对人群排序。
- 输出给用户时，只陈述**性质与客观影响**（合同主体、福利口径、履历可核验性）。
- 无论结论如何，最终决策与偏好由用户自己做。
