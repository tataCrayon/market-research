# 移动端调研数据源与检索模板

> 通用商业调研的默认工具箱（G2 / Capterra / Trustpilot / Crunchbase / SimilarWeb）
> **在中国移动端场景严重失真**——那里的用户不写 G2 评论，他们写应用商店评论、小红书笔记和贴吧吐槽。
> 本文件给的是移动端的补充清单。

---

## 一、中国移动端专属信号源

| 类别 | 来源 | 拿什么信息 |
|---|---|---|
| 商店评论 | App Store 中国区、酷安、华为/小米/荣耀商店评论区 | **按「最新」排**，不要看精选，并对照下载量一起观察：下载高而更新停 = 僵尸产品 |
| 社交舆情 | 小红书、知乎、贴吧、微博 | 真实吐槽、求助帖、「求推荐 <品类>」帖给你的就是未被满足的需求原文 |
| 小程序生态 | 微信搜一搜、相关公众号、小程序本身 | 搜一搜结果位次 = 小程序端的 SEO 现实 |
| 榜单与估算 | 七麦数据、点点数据（免费档即可） | 分类榜位置、排名趋势、关键词覆盖 |
| 政策与合规 | 见 [three-platform-constraints.md](three-platform-constraints.md) | 上架 / 资质 / 备案 / 分成 |

## 二、全球 / 通用源（保留）

- 规模与行业：Statista（免费片段）、Grand View Research 摘要、上市公司财报与 SEC 备案
- 竞品健康：Crunchbase（融资/投资方/成立时间）、LinkedIn 人数趋势
- 趋势：Google Trends、Product Hunt、Reddit / Hacker News 讨论
- 渠道：Google Ads 透明度中心、Meta 广告资料库（看竞品在投什么）

## 三、检索语句模板

```
# 找竞品
<品类词> app          <品类词> 小程序
<英文品类> app store best    <品类> site:mp.weixin.qq.com
"<品类词>" 排行 2026          <品类> alternative reddit

# 找用户抱怨（最值钱）
<竞品名> 难用 / 吐槽 / 智商税      <竞品名> review complaint
"<品类词>" 有什么推荐 知乎         <竞品名> 为什么 不能 <某功能>

# 找替代与相近品类
<竞品名> vs           <竞品名> comparison <current year>
similar apps to <竞品名>

# 政策取证（必须做）
<端名> 上架 要求 <current year>          <端名> 审核 被拒 常见原因
<端名> 虚拟支付 规定                     <品类> 需要什么资质 app 备案
App Store Review Guidelines <issue>      <端名> <品类> review policy
```

## 四、检索纪律

- **中文名搜不到就换英文，反之亦然**；再换品类词、再换榜单入口。
- **搜不到 ≠ 没有**。写「未检索到」，不写「没人做过」。
- **预算 ≤15 次，其中 1/3 以上必须投给政策取证**。市场与竞品检索天然顺手，政策检索最容易被偷工。
- 每条命中记录：`来源 | 性质（官方 / 媒体 / 用户原话 / 我的推测）| 链接 | 查证日期`。
- 报告里「检索到的事实」与「我的推理」分两区写，不得混排。
