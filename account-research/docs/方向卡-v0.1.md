# 方向卡 v0.1｜账号知识库工作台

> **一页纸，只写方向与功能边界。**详细规格（6 张表、校验器、字段、验收）见 [prd-v0.1-账号知识库与领域矩阵.md](prd-v0.1-账号知识库与领域矩阵.md)——两者冲突时**以本卡为准**，PRD 按本卡修订。

## 一句话

**本地 Web 工作台（确定性代码）+ DSH 当拆解引擎（headless 调用）+ 本地文件当唯一数据源。**

```
┌─────────────────────── 工作台：本地页面，不调模型 ───────────────────────┐
│  上传（HTML / 粘贴 / 截图）→ 解析 → 入库 → 矩阵 · 统计 · 总览 · 检索 · 补充  │
└───────────────┬──────────────────────────────────────▲──────────────────┘
                │ 需要"拆解推理"时（每账号一次）        │ 结构化产物回填
                ▼                                      │
        dsh headless "<拆解任务>"  ── skill + agent ────┘
                （方法论留在这里迭代，工作台不用改）
                         │
                    data/ 本地文件（唯一真相源）
```

## 形态判决

| 候选 | 判断 | 理由 |
|---|---|---|
| 自建 Agent runtime | ❌ | 执行循环不是瓶颈；`dsh headless` 已经现成 |
| **做进 DSH 页面里的插件** | ❌ | DSH 的 UI 插件只能挂在既有槽位（如 `conversation.composer.dock`），且**明文禁止替换 app root 或塞入第二个应用**——装不下一个"检索 + 统计 + 总览"的工作台 |
| 纯 Skill（现状） | ❌ | 承载不了上传、管理、检索、统计 |
| **本地工作台 + dsh headless** | ✅ | 页面归页面、脑归 DSH、数据归本地文件；换引擎不用重写页面 |

## 五条需求 → 归属

| # | 你要的 | 由谁实现 | 需要模型吗 | 期 |
|---|---|---|---|---|
| 1 | 集成 DSH 的能力 | **引擎层**：`dsh headless "<任务>"` 子进程调用 | 是（就是它） | P1 |
| 2 | 可检索、持续分析的可视化操作页面；HTML / 截图都能传 | 工作台前端 + 解析器 | 截图需读图模型，其余**不需要** | P0 |
| 3 | 拆解产物要能满足需求、实现目标 | `findings` / `playbook` / `hypotheses` 三张表 | 是 | P0–P1（**"目标"待定，见下**） |
| 4 | 产物可管理：补充、扩展、同领域账号归纳、检索 | 库 + 编辑/追加界面 + 标签 | 归纳标签可半自动，不强依赖 | P0 |
| 5 | 分析、统计、总览 | 确定性聚合 + 图表 | **不需要** | P0 |

> **这张表最重要的信息在第 4 列**：五条里四条是确定性的。上传、解析、入库、检索、统计、矩阵**全都不需要模型**——用模型做这些只会更慢、更贵、更不可复现。模型只出现在两处：拆解推理、截图读图。

## 三条不可让步

1. **确定性优先**。能写成代码的，不交给模型。规则：结果需要每次一致 → 代码；需要归纳判断 → 模型。
2. **数据全本地 + 零爬虫**。工作台只处理用户**已上传**的文件；不访问平台域名、不模拟点击、不批量存档。红线不因产品化放松（[AGENTS.md:11](../AGENTS.md#L11)）。
3. **表是唯一真相源**，页面与报告都是渲染视图（三处数字必须同源）。

## 先做哪一步

| 步 | 交付 | 为什么先做这个 |
|---|---|---|
| **S1** | 上传 → 解析 → 入库 → 矩阵/统计页面（**不含任何 AI**） | 直接消灭"整理得差 / 可视化差 / 不能检索"，且全是确定性工作，不会因模型漂移返工 |
| S2 | 页面上一个「拆解」按钮 → `dsh headless` → 产物回填 | 把 AI 接进来，但只接在需要它的那一步 |
| S3 | 采集提效：粘贴/截图的归属校验 → 浏览器插件 | 采集是唯一被实测的瓶颈，但排在数据层之后 |

## 明确不做

独立 Agent / RAG 问答（N≥30 再说）/ 爬虫 / 多平台 / 账号评分排行榜 / 涨粉预测（公开数据取不到，只能进假设表）。
