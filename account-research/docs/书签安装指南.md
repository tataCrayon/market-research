# 安装「AR采集」书签：装一次，之后一篇 3 秒

> 目标：把详情页采集从「Ctrl+A → 复制 → 开记事本 → 粘贴 → 存盘 → 丢进 inbox」六步，压到**两步**：
> **点书签 → 文件自动落到下载目录**。剩下的入库由 `ar ingest` 一条命令完成。

## 装法（30 秒，一次性）

1. Chrome / Edge 里开一个新标签，随便打开一个网页（必须不是在书签管理器里操作）
2. 按 **Ctrl+D** 收藏 → 名称填 `AR采集` → 位置选**书签栏** → 保存
3. 在书签栏上**右键这个书签 → 修改**
4. 名称保持 `AR采集`，把 **网址** 整个替换成下面这一行（必须保留开头的 `javascript:`）

```
javascript:(function(){const B="===AR-NOTE-v1===",E="===END===",c=s=>(s||"").replace(/\s+/g," ").trim(),u=location.href,m=u.match(/(?:explore|discovery\/item)\/([0-9a-f]{24})/i),id=m?m[1]:"",n=[document.querySelector("#noteContainer"),document.querySelector(".note-detail-mask .note-container"),document.querySelector("[class*='note-content']"),document.querySelector(".note-scroller")].filter(Boolean),sc=n[0]||document.body,t=c(sc.innerText||""),ti=c((document.querySelector("#detail-title")||{}).textContent||(document.querySelector(".note-content .title")||{}).textContent||document.title.replace(/ - 小红书.*$/,"")),bar=c((document.querySelector(".interact-container")||sc).innerText||"").slice(0,120),cand=(bar.match(/\d+(?:\.\d+)?\s*[万wW]?/g)||[]).slice(0,8).join(" | "),v=sc.querySelector("video"),mm=t.match(/\b(\d{1,2}:\d{2})\b/),blk=[B,"note_id: "+id,"title: "+ti,"published: ","likes: ","collects: ","comments: ","shares: ","duration: "+(mm?mm[1]:(v&&v.duration?String(v.duration):"")),"human_note: ","url: "+u.split("?")[0],"raw_len: "+t.length,"body_head: "+t.slice(0,40),"bar_text: "+bar,"candidates: "+cand,E].join("\n"),blob=new Blob([blk],{type:"text/plain;charset=utf-8"}),a=document.createElement("a");a.href=URL.createObjectURL(blob);a.download="ar-note-"+(id||"unknown")+".txt";a.click();URL.revokeObjectURL(a.href);alert((id?"已保存 ar-note-"+id+".txt":"没认出 note_id")+"\n\n互动栏原文：\n"+(bar||"（没找到，请看页面）")+"\n\n下一步：ar ingest")})();
```

## 用法（每篇 3 秒）

1. 笔记整页打开（**不要从主页点开弹层**）
2. 点一下 `AR采集` → 浏览器下载 `ar-note-<note_id>.txt`
3. 攒几篇后一起丢进 `account/inbox/`，跑 `ar ingest`

## 它能拿到什么、拿不到什么

| 字段 | 能否拿到 |
|---|---|
| `note_id` / 标题 / 正文首 40 字 / 正文长度 | ✅ 自动 |
| 时长（视频） | ✅ 自动（页面有 `mm:ss` 或 video 元素时） |
| 话题标签 | ✅ 自动（随正文一起进 `raw_len` 覆盖范围） |
| **赞 / 藏 / 评** | ⚠️ 弹窗会显示**互动栏原文**，你照着填——工具不解析数字 |
| 分享数 | ❌ 页面上只有图标没有数字 |
| 发布时间 | ❌ 只显示「3天前」这种相对值 |

**为什么数字不自动填**：`like-wrapper` 这类选择器平台一改就失效，自动填会变成**静默错数据**。
宁可多一次人工确认（3 秒），不要一次错数入库。

## 它不做什么（改之前先读）

- ✗ 不发网络请求：没有 `fetch` / `XHR` / `WebSocket`
- ✗ 不翻页、不滚动加载、不批量
- ✗ 不读 Cookie、不碰会话
- ✗ 不模拟平台控件——唯一一次 `click()` 点在自己新建的下载链路上，下载的是**本机内存里的字符串**

**这是「人打开页面 → 人触发 → 工具读已加载 DOM」**，与 Ctrl+A 复制同性质，只是省掉了复制粘贴两步。

## 如果书签装不上（Chrome 拦截 `javascript:`）

两个替代，都不用装任何东西：

1. **F12 打开控制台 → 粘贴 js 文件内容 → 回车**（同样能下载 txt，但要多几次点击）
2. **退回 Ctrl+A 复制** → 存成 txt → 丢 inbox（`ar parse-text` 走同一条入库路径）
