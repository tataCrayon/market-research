# 全自动采集闭环：一次点击 → 自动入库（2026-11-13）

> 目标：**采完就完事**。点扩展图标 → 文件落到下载目录 → 命令行自己入库，人不回终端。

## 1. 最终用法（推荐这一条，Chrome 设置一个字都不用改）

```powershell
cd D:\Projects\MyProjects\market-research\account-research
python ar.py watch --path "%USERPROFILE%\Downloads" --pattern "ar-page-*"
```

然后：**正常浏览 → 点扩展图标 → 什么都不用做**。

`ar watch` 每 3 秒扫一次下载目录，看见 `ar-page-*.mhtml` 就：
拆包 → 解析 → 写表 → 跑 OCR → 归档 → 把 MHTML 删掉。

### 为什么用 `--pattern` 而不是「把下载目录设成采件箱」

你的下载目录现在有 **120 个文件**。如果只按「HTML/MHTML 后缀」过滤，
别人的 `xxx.html`、你下载的网页存档，**全都会被收进证据库**——而它们根本不是采的数据。

实测这条过滤没做的后果（端到端跑出来的）：

```
下载目录里现在有 3 个文件：
   ar-page-6aed6c2b000000000803f69c.mhtml   ← 要收
   季度报表.html                            ← 别人的，不能收
   安装包.zip                               ← 不能收
```

加 `--pattern "ar-page-*"` 后：前两个原封不动，只有 `ar-page-*` 被消费。

**为什么文件名能当白名单**：扩展生成的名字是固定的
`ar-page-${noteId || "unknown"}.mhtml`，前缀是我们自己定的，不会和别人的下载撞。

## 2. 备选：把 Chrome 下载目录改到 `account/inbox/`

```
Chrome → 设置 → 下载内容 → 位置 → 更改 → account\...\account\inbox
```

好处：连 `--pattern` 都不用加，目录天然干净。
代价：**你所有的下载都会落到那里**（要自己定期清理）。

## 3. 这一轮补了什么（都是为了「能一直开着」）

| 问题 | 修法 |
|---|---|
| 开着过夜，第二天采的记成昨天 | `--on` 默认从「启动时的日期」改成 **None**，入库那一刻才取 |
| 读到下载了一半的文件 | `--settle`（默认 1 秒）：文件 mtime 距现在不足就先不碰 |
| 无法放进定时任务 / 无法确定性测试 | `--once`：扫一遍就退出 |
| 下载目录里别人的 `.html` 被误收 | `--pattern` 白名单，可重复、可逗号分隔 |
| **`ar watch` 遇到详情页必崩** | 见下节 |

## 4. 端到端跑出来的真 bug：`Namespace` 少一个字段

端到端把「带 16 张图的 MHTML」丢进模拟下载目录，结果：

```
── 发现 ar-page-6aed6c2b000000000803f69c.mhtml
📦 拆包成功（2 个子资源）
✅ 详情页 note_id=6aed6c2b…（赞 318 / 藏 73 / 评 14 / 分享 ⬜）
⚠️ 入库失败：'Namespace' object has no attribute 'no_ocr'
（文件留在原地，修好后再跑）
```

**根因**：`cmd_ingest` 里写的是

```python
if detail_ready and not args.no_ocr:      # ← 从命令行跑时 args 有这个字段
```

而 `cmd_watch` 自己拼一个 Namespace 传给 `cmd_ingest`，里面**没有** `no_ocr`。

**为什么它藏了一整天**：`and` 是**短路求值**。
`detail_ready` 为空（只丢主页存档）时，右边根本不会被求值，永远不报错。
而原有测试**只丢主页存档进去**，所以全绿；
真实用法里丢进去的恰恰是详情页，于是 `ar watch` 每一篇都崩。

**修法**：`getattr(args, "no_ocr", False)`，并补一条「详情页走完整条路」的测试。

**教训**：`cmd_watch` 调 `cmd_ingest` 靠的是「拼一个看起来一样的 Namespace」——
这是一个**只靠约定维持的隐式契约**，谁给 `cmd_ingest` 加一个参数，
这里就静默地少一个字段。正确的做法是让 `cmd_watch` 复用同一份默认值。

## 5. 顺带确认：别人的文件一个都没被动

端到端结果：

```
用户的 季度报表.html 还在吗：True
用户的 安装包.zip 还在吗  ：True
MHTML 已被消费（应消失）  ：True
归档的 HTML：['ar-page-…-160235.html', 'ar-page-….html']
```

「不碰非采集文件」不只是过滤，还有落地保证：`scan()` 只返回通过白名单的路径，
其余文件**连 stat 都不做**（不删、不挪、不打印），所以误删风险为零。
