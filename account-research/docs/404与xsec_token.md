# 那个 404 是什么：不是封号，是链接缺了 token（2026-10-28）

## 1. 先给结论

| 问题 | 答案 |
|---|---|
| 是不是被封号了？ | **不是。** 你的账号没被限制，登录态也没失效 |
| 那个 404 是哪个笔记？ | `6ac719230000000014039dd8` = **卡兹克那篇 4566 赞**（已在库里） |
| 为什么会 404？ | **链接缺 `xsec_token`**。裸 `/explore/<id>` 现在打不开 |
| 要扫码吗？ | **不用扫。** 关掉那个 tab，从主页点进去就行 |
| 我生成的链接有问题吗？ | **有。之前全部是裸链接，都会 404。现已修复。** |

**error_code=300031 的原文是「当前笔记暂时无法浏览」**——这是**访问参数不完整**，
不是「你违规了」。真正的封禁提示不会长这样。

## 2. 证据链

### 2.1 那个 URL 自己就说了原因

```
https://www.xiaohongshu.com/404?source=/404/sec_BmWljbHR
  ?redirectPath=https%3A%2F%2Fwww.xiaohongshu.com%2Fexplore%2F6ac719230000000014039dd8
  &error_code=300031
  &error_msg=当前笔记暂时无法浏览
```

我生成的旧链接正是 `https://www.xiaohongshu.com/explore/6ac719230000000014039dd8`
—— **一个 query 都没有**。它被重定向到 404，说明平台现在要求带访问参数。

### 2.2 这个 token 本来就在你自己的存档里

我把你保存的主页存档翻了一遍：

```
卡兹克-主页-20261022.html  → 11 组 (noteId, xsecToken)
知新的AI笔记 - 小红书.html  → 16 组
全 account/ 目录            → 103 个 note_id 的 token
```

结构长这样：

```json
{"noteId":"6ac719230000000014039dd8","noteCard":{...},"xsecToken":"ABJV9aUMPAG9oBlaJ8Yvqqs91JzO0_MLkQY5mGBWe86AQ="}
```

**所以这不是去"偷凭证"**——那是平台在渲染你主页时**发给你浏览器、并且已经存进你硬盘**的访问参数。
我只是把它读回来，拼进链接。

## 4. 但 token 会过期——这是必须知道的限制

token 是**会话级**的，我从你 10-22 / 10-28 的存档里读出来，它可能已经失效。

所以看板上加了明确的降级提示：
- 有 token → 正常链接
- **无 token → 标红「无 token」，页顶用醒目色块说明会 404**

**最稳的路径永远是：回该账号主页 → 点进那一篇。** 那条路径由浏览器当场向平台请求，
一定带新鲜 token。我生成的清单是**省事**，不是**唯一正确**。

## 5. 你现在该做什么

1. **关掉那个 404 标签页**——什么都不用管，不用扫码
2. **别用旧的那两份清单**（已覆盖，但你若开了旧 tab 记得刷新）
3. 重新打开 [爆款优先看板](todo-爆款优先.html) → 里面的 4 个链接现在带 token
4. 如果某个还是 404 → **回主页点进去**，那条永远能开
