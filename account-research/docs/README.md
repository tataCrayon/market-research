## 规划

- `roadmap.md` —— 产品路线图（Skill 先行 → 放大，里程碑与验证门）：**尚未建**，也不该建。当前顺序以 [`方向卡-v0.1.md`](方向卡-v0.1.md) 的 S1–S3 为唯一真相源，另写一份路线图只会多一处会漂的副本。现状：**S1 数据层 ✅（CLI 形态，无 Web 页）/ S2 拆解 ✅（`ar debrief`，无按钮）/ S3 采集提效（浏览器插件）未开工**。
- ADR —— 一次性架构决策的上下文与后果：**尚未建**，也没有非建不可的决策在等它。`方向卡-v0.1.md` 已承担形态判决，`data-layer.md` §8 已承担拆解分工判决；等到出现「两个都能用、选了就难改」的决策再开第一条。


## 一个原则

本目录记录的是**过程与代价**，不是结论。结论在 `../skill/examples/`。产品化的判断依据应该是「哪一步最费人的时间」，而不是「哪一步听起来最像功能」。
