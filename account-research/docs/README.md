## 规划

- `roadmap.md` —— 产品路线图（Skill 先行 → 放大，里程碑与验证门）
- ADR（架构决策记录）—— 如「解析器语言选型」「插件 vs Web 的先后顺序」等一次性决策的上下文与后果

状态：路线图待建。**第一条 ADR 建议就是「L2 插件 vs L3 Web 的先后」**——case-001 复盘给出了反直觉证据（摩擦 80% 在采集侧，而 Web 工具消除不了采集摩擦），但最终排序需用户决策，不在此预设。

## 一个原则

本目录记录的是**过程与代价**，不是结论。结论在 `../skill/examples/`。产品化的判断依据应该是「哪一步最费人的时间」，而不是「哪一步听起来最像功能」。
